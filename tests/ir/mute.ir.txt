Bundle Pausing  author=you
|--- Need Vein.Console
|--- Event @Paused
|--- Shard Menu
|    |--- Var t: int = Int 0
|    `--- EachTick
|         |--- Assign += t
|         |    `--- Int 1
|         |--- If
|         |    |--- Cond = Binary ==
|         |    |    |--- Ref t
|         |    |    `--- Int 3
|         |    `--- Then
|         |         |--- Call print
|         |         |    `--- Str "menu opens"
|         |         |--- Mute Game
|         |         `--- Emit @Paused
|         `--- If
|              |--- Cond = Binary ==
|              |    |--- Ref t
|              |    `--- Int 5
|              `--- Then
|                   |--- Call print
|                   |    `--- Str "menu closes"
|                   `--- Unmute Game
`--- Shard Game
     |--- Var frame: int = Int 0
     |--- EachTick
     |    |--- Assign += frame
     |    |    `--- Int 1
     |    `--- Call print
     |         `--- Concat
     |              |--- Str "play frame "
     |              |--- Ref frame
     |              `--- Str ""
     `--- Hear @Paused as p
          `--- Call print
               `--- Str "game heard the pause"
