|    |--- Event @Render
|    |--- Event @Response
|    |    |--- Field status: int
|    |    `--- Field body: string
|    |--- Shape $Heading
|    |    `--- Field text: string
|    `--- Shape $Button
|         |--- Field id: string
|         |--- Field class: string
|         |--- Field label: string
|         `--- Field onclick: string
|--- Builder Heading  kind=html
|    |--- Include $Heading
|    `--- Field markup = Concat
|         |--- Str "<h1>"
|         |--- Ref text
|         `--- Str "</h1>"
|--- Builder Button  kind=html
|    |--- Include $Button
|    `--- Field markup = Concat
|         |--- Str "<button id=\""
|         |--- Ref id
|         |--- Str "\" class=\""
|         |--- Ref class
|         |--- Str "\" onclick=\""
|         |--- Ref onclick
|         |--- Str "()\">"
|         |--- Ref label
|         `--- Str "</button>"

|    `--- Hear @Request as req
|         |--- Bring Heading
|         |    `--- Arg = Str "Counter"
|         `--- Bring Button
|              |--- Arg = Str "inc"
|              |--- Arg = Str "primary"
|              |--- Arg = Str "+1"
|              `--- Arg = Str "inc"

|    `--- Hear @Request as req
|         `--- Emit @Render

               |--- Arg status = Int 200
               `--- Arg body = Concat
