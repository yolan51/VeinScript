|--- Need Vein.Console
|--- Event @Chat
|    `--- Field text: string
|--- Shard Ledger
|    `--- RunOnce
|         `--- Emit @Chat
|              `--- Arg text = Str "hi from Ledger"
|--- Shard Billing
|    `--- RunOnce
|         `--- Emit @Chat
|              `--- Arg text = Str "hi from Billing"
|--- Shard Spammer  carries=[#Banned]
|    `--- RunOnce
|         `--- Emit @Chat
|              `--- Arg text = Str "hi from Spammer"
|--- Shard Kiosk
|    `--- RunOnce
|         `--- Emit @Chat
|              `--- Arg text = Str "hi from Kiosk"
|--- Shard AllBut
|    `--- Hear @Chat as c  audience=[not !Ledger not !Spammer]
|         `--- Call print
|              `--- Concat
|                   |--- Str "all-but: "
|                   |--- Path c.text
|                   `--- Str ""
|--- Shard OnlyLedger
|    `--- Hear @Chat as c  audience=[!Ledger]
|         `--- Call print
|              `--- Concat
|                   |--- Str "only-ledger: "
|                   |--- Path c.text
|                   `--- Str ""
`--- Shard Unbanned
     `--- Hear @Chat as c  audience=[not #Banned]
          `--- Call print
               `--- Concat
                    |--- Str "unbanned: "
                    |--- Path c.text
                    `--- Str ""
