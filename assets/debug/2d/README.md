# 2D debug assets

`debug-icons-atlas.png` is a 4x4 high-contrast diagnostic icon atlas generated for the editor's
sprite/texture path. It is intended for placeholder entities, missing-asset checks, UI overlays, and
renderer smoke tests rather than shipped art.

The image was generated with the built-in image generation workflow using a transparent-background,
flat-raster debug-icon prompt. Keep it as one atlas until the editor has sprite-sheet region support.
