# VeinScript — Worked Example: `demo.vein` End-to-End

Traces one program through every stage. It is the **acceptance artifact**: every construct is defined
in [LANGUAGE.md](LANGUAGE.md), desugared in [DIALECTS.md](DIALECTS.md), lowered in
[IR-SPEC.md](IR-SPEC.md), and C#-mapped in [BACKEND-CONTRACT.md](BACKEND-CONTRACT.md). A gap anywhere
is a spec bug.

Stages: **Source → AST → desugared core AST → HIR → emitted C#**.

---

## Stage 0 — Source (IOP)

The current [samples/demo.vein](../samples/demo.vein). Note the IOP shape: data in `shape`/`event`,
behavior in `shard`, iteration via `target`, concurrent-write policy via `folds sum`, field mutation
via `-=` (no `push`, no `class`).

```
bundle Demo {
    use Core
    publicator DemoCore {
        shared("Hit points and mana for any living identity.")
        shape $Health { hp: int folds sum, mp: int }
        shared("Damage applied after mitigation.")
        event @Damaged { amount: int, victim: Entity }
    }
    SF clamp(v: int, lo: int, hi: int) -> int {
        if v < lo { return lo }
        if v > hi { return hi }
        return v
    }
    shard Drain {
        target $Health #Enemy as self {
            each tick {
                ::Health.hp -= 1
                chance 30% { emit @Damaged { amount: 5, victim: self } }
            }
        }
        settled { if ::Health.hp <= 0 { mark self #Dead } }
    }
}
```

## Stage 1 — AST (parser output, `veinc ast`)

IOP nodes are first-class; desugaring is the next stage. Abbreviated:

```
BundleDecl "Demo"
  UseDecl "Core"
  PublicatorDecl "DemoCore"
    ShapeDecl "Health" doc="Hit points…"  fields=[hp:int folds sum, mp:int]
    EventDecl "Damaged" doc="Damage…"      fields=[amount:int, victim:Entity]
  FuncDecl SF "clamp" (v:int, lo:int, hi:int) -> int
    IfStmt (< v lo) { Return lo }
    IfStmt (> v hi) { Return hi }
    Return v
  ShardDecl "Drain"
    TargetBlock components=[$Health] tags=[#Enemy] bind="self"
      EachTick
        AssignStmt ::Health.hp -= 1
        ChanceStmt 30%
          EmitStmt @Damaged { amount: 5, victim: self }
    Settled
      IfStmt (<= ::Health.hp 0) { MarkStmt self #Dead }
```

## Stage 2 — Desugared core AST

IOP surface sugar → plainer core ([DIALECTS.md §1](DIALECTS.md#1-surface-sugar--core-desugaring)).
Sigils gone; `chance`/`mark`/`emit` become `if`/runtime calls; `folds` becomes field metadata;
`each tick`/`settled` become shard methods that `target` the query.

```
BundleDecl "Demo"
  TypeDecl "Health"  kind=Component  fields=[hp:int @fold(sum), mp:int]   @component
  TypeDecl "Damaged" kind=Message    fields=[amount:int, victim:Entity]   @message
  TypeDecl "Dead"    kind=Tag        fields=[]                            @tag
  FuncDecl "clamp" pure (v:int,lo:int,hi:int)->int
    if (< v lo) { return lo }; if (> v hi) { return hi }; return v
  ShardDecl "Drain"  @system @query(components=[Health],tags=[Enemy],bind=self)
    method "tick"()->void
      target query as self {
        self.Health.hp = (+ self.Health.hp -1)               // -= , a fold contribution
        if (< (call random) 0.30) {                          // chance 30%
          call Emit (Damaged { amount: 5, victim: self })    // emit
        }
      }
    method "settled"()->void
      target query as self {
        if (<= self.Health.hp 0) { call AddTag self Dead }   // mark
      }
```

## Stage 3 — HIR (`veinc ir`, per [IR-SPEC.md §5](IR-SPEC.md#5-textual-dump--veinc-ir-file))

Fully typed, resolved; `shard` is an `IrShard` (no `IrClass`); loops are `IrLoop(Target)`.

```
module Demo
  type Health : Component { hp: int folds sum, mp: int }
  type Damaged : Message   { amount: int, victim: Entity }
  type Dead : Tag { }
  fn clamp(v: int, lo: int, hi: int) -> int  [pure]
    if (< v lo) then { return lo }
    if (> v hi) then { return hi }
    return v
  shard Drain  @system @query(components=[Health], tags=[Enemy], bind=self)
    fn tick() -> void
      loop target self: Entity in query
        assign self.Health.hp = (+ self.Health.hp -1)
        if (< (call random) 0.30) then
          call Emit (Damaged { amount: 5, victim: self })
    fn settled() -> void
      loop target self: Entity in query
        if (<= self.Health.hp 0) then
          call AddTag self Dead
```

## Stage 4 — Emitted C# (`veinc build --backend csharp`, per [BACKEND-CONTRACT.md §2](BACKEND-CONTRACT.md#2-the-c-transpiler-first-backend))

`Demo.g.cs`. `int`→`long`; `shard`→the only C# class (`: SystemBase`); folded write → `Contribute`.

```csharp
// <auto-generated />
namespace Runtime.Demo;

/// <summary>Hit points and mana for any living identity.</summary>
public struct Health : IComponent { [Fold(Reducer.Sum)] public long hp; public long mp; }

/// <summary>Damage applied after mitigation.</summary>
public struct Damaged : IEvent { public long amount; public int victim; }

public struct Dead : ITag { }

public static class DemoFns
{
    // pure
    public static long clamp(long v, long lo, long hi)
    {
        if (v < lo) { return lo; }
        if (v > hi) { return hi; }
        return v;
    }
}

public sealed class Drain : SystemBase   // @query(components=[Health], tags=[Enemy], bind=self)
{
    protected override void Tick()
    {
        foreach (var self in World.Query<Health>().With<Enemy>())
        {
            self.Contribute<Health>(h => h.hp += -1);   // folded (sum)
            if (Runtime.Random() < 0.30)
                World.Emit(new Damaged { amount = 5, victim = self.Id });
        }
    }

    protected override void Settled()
    {
        foreach (var self in World.Query<Health>().With<Enemy>())
            if (self.Get<Health>().hp <= 0)
                World.AddTag<Dead>(self);
    }
}
```
